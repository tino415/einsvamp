# einsvamp

Generates tilings of the **Spectre** — the chiral aperiodic monotile, nicknamed
the "vampire einstein" because it tiles the plane without reflections. Renders
live to SVG in the browser and exports a standalone `.svg`.

Vite + vanilla TypeScript, no runtime dependencies. Builds to plain static files
in `dist/` for upload to Cloudflare Pages.

## Background

The hat monotile (2023) tiles the plane aperiodically but needs both the hat and
its mirror image. Its equilateral cousin **Tile(1,1)** avoids that — but only if
you forbid reflections by fiat. Replacing Tile(1,1)'s straight edges with a
matched S-curve gives the **Spectre**, whose mirror image simply cannot fit
against it: bulges meet bulges instead of dents. That makes it a *strictly*
chiral aperiodic monotile, and it is why the "Curved edges" toggle is a
mathematical switch, not a decorative one.

The tiling is generated by a substitution system over nine clusters
(Gamma, Delta, Theta, Lambda, Xi, Pi, Sigma, Phi, Psi). Eight expand to eight
children; **Gamma** is the *Mystic*, a two-tile compound — and crucially both
halves have the same handedness.

## Development

The dev environment comes from Nix. `default.nix` and `.dir-locals.el` are
tangled from `~/org/repositories.org` — edit the org file, not them.

```sh
nix-build -o .nix      # after tangling
nx npm install
nx up                  # dev server on http://dev.local:4114
```

| Command | What it does |
| --- | --- |
| `nx npm run dev` | Dev server on `dev.local:4114` |
| `nx npm run build` | Type-check, then build static `dist/` |
| `nx npm run check` | Geometric assertions on the tiling core (no browser) |
| `nx npm run e2e` | Playwright run against the dev server, with screenshots |
| `nx npm run render out.svg key=value…` | Render an SVG headlessly |

`check` is the important one: a wrong angle or substitution rule still *renders*,
it just renders something that is not the Spectre. It verifies the polygon is
equilateral and closes, that every edge is shared by exactly one or two tiles
(no gaps, no overlaps), that no tile is reflected relative to any other, that
tile counts match the published sequence (9, 71, 559, 4401, 34649), and that the
inflation factor converges to 2.80588.

## Deploying

```sh
nx npm run build
```

Upload `dist/` to Cloudflare Pages (build command `npm run build`, output
directory `dist`). `base` is relative, so it also works from a subpath. Nothing
is fetched from any external host at runtime.

## Parameters

All parameters live in one schema in `src/params.ts`; the control panel, the
state object and the URL hash are generated from it, so adding a knob is a
one-line change. The current settings are encoded in the URL — copy the link to
share an exact tiling.

Groups: **Tiling** (system, subdivision depth, start cluster), **Shape** (curved
edges, curve depth/start/end, tile inset, corner rounding), **View** (zoom, pan,
rotation, clipping), **Colour** (eight colouring modes, eight palettes, hue /
saturation / lightness / opacity), **Stroke**, **Background**, **Noise** (seed,
position and rotation jitter) and **Export** (size, coordinate precision).

Drag the canvas to pan, scroll to zoom.
